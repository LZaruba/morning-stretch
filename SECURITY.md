# Security policy

## Supported versions

Only the latest release of Morning Stretch receives fixes.

## Reporting a vulnerability

Please do not report security problems in public issues. Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/LZaruba/morning-stretch/security/advisories/new) (*Security → Report a vulnerability*).

Describe the problem, how to reproduce it and which versions are affected. We will reply as soon as we can and let you know how we plan to fix it.
